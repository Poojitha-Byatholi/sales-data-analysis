# Sales Data Analysis Project

## 📌 Objective

To analyze retail sales data and identify business insights using Python.

## 🛠️ Tools Used

* Python
* Pandas
* Matplotlib

## 📊 Analysis Performed

* Data cleaning and preprocessing
* Sales analysis by category, region, and time
* Data visualization using charts

## 🔍 Key Insights

* Technology category generates highest sales
* Furniture shows lower profitability
* Western region performs best
* Discounts negatively impact profit

## 🚀 Conclusion

This project demonstrates how data analysis can be used to extract meaningful business insights and support decision-making.
